One-page newspaper image summing up the world news of Wednesday 18 November 2026, drawn entirely by code (Node 22, standard library only, deterministic).

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Writes `out/entry.png` (1024×1024 PNG; two runs write byte-identical files).
